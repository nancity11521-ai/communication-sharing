# 通信共享 · 跨设备通信共享 PRD

> Ulefone / RugOne 跨设备通信共享产品需求文档（PRD）
> 
> 版本 V2.0 | 2026-10-12

## 文档简介

本文档定义了 Ulefone / RugOne 品牌的跨设备通信共享能力，覆盖两个核心场景：

1. **iPhone × Ulefone/RugOne** — 单向能力借用（来电 / 短信 / 通知流转）
2. **Android × Android** — 双向能力交换（移动网络 / 通话 / 短信 / 定位增强），跨品牌开放

## 核心特性

- **跨品牌开放互联**：不限于自家品牌，支持四级接入（自家设备 / 合作品牌 / 第三方 Android / iPhone）
- **四层协议栈**：发现 → 传输 → 协议（ULP）→ 应用
- **14 章完整 PRD**：从背景目标到上线计划，含功能需求、页面交互、非功能需求、埋点方案、风险应对
